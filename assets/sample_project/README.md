# Sample Project

`sample-project.aep` is the bundled beginner project (1080p30, two markers,
two subtitle track stubs).

The referenced media file `sample/clip01.mp4` is a small royalty-free clip.
It is **not committed to the repository** (binary media is distributed with
the release payload, not the source). When it is absent, the Media Bin shows
its "Missing" badge and the Relink action — which is exactly the behavior the
missing-media workflow should exercise.

Open it from File ▸ Open (or the Welcome screen once recent projects are wired
in M2) and you can try the workspace, timeline ruler, transport, and
subtitles table immediately.
