# Arena Edit — Decisions Log

Conservative resolutions of ambiguities in the spec (working rule #4). Each
decision stays valid until superseded; superseded entries are kept with
`SUPERSEDED BY`.

| ID | Decision | Rationale |
|----|----------|-----------|
| D-001 | **Qt Widgets** (not QML) for the UI | Dense NLE layout (docks, custom-painted timeline/monitor), mature UI Automation/Narrator support for the accessibility targets, simple per-monitor DPI, and 120–180 ms motion is fully doable with QPropertyAnimation. QML's retained-mode scene graph is not needed until (if ever) the compositor moves to QQuick items. LGPL-compatible either way; Widgets gives the smaller, more predictable binary. |
| D-002 | **JSON translation catalogs** (allowed by the spec's "or a JSON equivalent") instead of .ts/.qm | Drop-in languages with zero build steps (spec: "drop in a new translation file and it appears automatically"), trivial RTL metadata per locale, no lrelease dependency, and the loader can validate/merge at runtime. Qt Linguist can still be used to *author* translations from the JSON (round-trip is trivial). |
| D-003 | **Cross-platform core, Windows-only targets guarded** | The sandbox/CI here is Linux; the product targets Windows. All Windows-only code (WASAPI, DPAPI, D3D11, registry theme probe, Inno packaging) is behind `Q_OS_WIN` / CI Windows job. Platform-neutral logic (core, i18n, AI client, validator, themer) is verified on Linux with Qt 6.8 in CI; the Windows job verifies the rest. |
| D-004 | **i18n lookup is `translate()`, not `tr()`** | Qt's `Q_OBJECT` macro injects a `static inline tr(const char*, …)` into every QObject subclass when translations are enabled; a member `tr(const QString&)` coexists with it and string literals silently bind to the injected static (returns untranslated text). Verified against Qt 6.8.2. Renaming avoids the trap for all future QObject-based panels. |
| D-005 | **Project extension `.aep`** (JSON content) with schema `v1` | Short, editor-ish, clearly ours; content stays JSON so schema migrations and human diffs work. The optional `.aedit` zip bundle (assets) arrives in M1/M9. |
| D-006 | **AI off by default + one-time privacy notice + per-project budget persisted globally** | Spec: opt-in, privacy notice before first request, ~200 req/h anonymous limit. The budget window (hourly) is stored in settings so the status-bar meter survives restarts. |
| D-007 | **Translator model default = `auto`** | Free model IDs churn; `auto` resolves to the first `:free` model from the live `/models` list, and the user can pin any model from the list (Settings ▸ AI). A pinned model that disappears → the client reports the error and the user reselects; no silent model swap. |
| D-008 | **Reasoning-model streams are surfaced as text** | Real gateway responses (see AI_INTEGRATION.md) show `:free` reasoning models emit `delta.reasoning` with `delta.content: null`. The client appends whichever field is present so "Ask AI" is never blank; the final `finish_reason` (e.g. `length`) ends the stream. |
| D-009 | **Autosave = sidecar file + clean-exit marker** (not in-project versioning) | Simplest crash-safe scheme: `<project>.autosave` written every 60 s while dirty; `<project>.clean` written on clean exit. Launch prompts recovery only when autosave is newer than the project AND no clean marker exists. Both behaviors are unit-tested. |
| D-010 | **Media timeline stays LTR in RTL locales** | Per spec 3.6: time always flows left to right; only text-track content and the rest of the chrome mirror. Implemented by pinning `Qt::LeftToRight` on the timeline widgets while `QApplication::setLayoutDirection` mirrors the app. |
| D-011 | **GTest for unit tests** (per spec) with `gtest_discover_tests` | One test per CI invocation (isolated crashes); CMake zero-config on Debian/Windows vcpkg. |
| D-012 | **FFmpeg/whisper behind CMake options (OFF in M0)** | The skeleton must build without heavy dependencies; M1/M7 flip `ARENA_ENABLE_FFMPEG` / `ARENA_ENABLE_WHISPER`. Interface files (`media/`, `stt/`) define the contracts now and report availability honestly in tests. |
| D-013 | **API key: env var first, then local store (DPAPI on Windows)** | Spec order. The DPAPI path (CryptProtectData) compiles on Windows only; non-Windows dev builds fall back to the plain store file with a logged warning (dev convenience only; shipping targets are Windows). |
| D-014 | **No UPX by default; single portable .exe via static Qt where practical** | Per spec; decided in M9 with the actual dependency set (LGPL Qt shared DLLs staged next to the exe in the portable folder today). |
| D-015 | **`retranslateUi()` must never call `refreshProjectViews()`** | `refreshProjectViews()` ends with `retranslateUi()`; the reverse call created unbounded recursion (stack overflow SEGV) the moment a project existed and the UI retranslated — latent in M0, first hit by M1 auto-project creation on "add clip to timeline". Fix: `retranslateUi()` re-applies the project-specific labels (fps, timecode) directly instead of recursing. |
| D-016 | **Audio output uses the QIODevice sink model with non-blocking writes** | This environment's Qt 6.8 QAudioSink header exposes `QIODevice* start()`, `processedUSecs()`, `bytesFree()` (no `write(QByteArray)` / `processedFrameCount()`). Playback writes through the device returned by `start()` and positions from `processedUSecs()`. The write loop never blocks: it checks `bytesFree()` first and gives up after ~10 s without space, so `stopAudioPipeline()`'s `join()` cannot deadlock on a stalled or consumer-less device. |
| D-017 | **Wall-clock fallback when no audio device exists** | If the sink starts but yields no device (headless CI, machines without audio), playback falls back to the wall clock so video still plays; the audio path is simply absent. `positionSec()` already prefers the sink only when the pipeline is live. |
| D-018 | **Proxy strategy: skip small sources, deterministic cache** | A proxy is generated only when `source height > project proxy height` (default 540). Proxy file name is `proxy_<sha1(path|size)[:16]>.mp4` in the per-user cache dir; a fresh cache entry newer than the source is reused. Proxy failure degrades gracefully to full-resolution playback with a status message. |
| D-019 | **All export output streams use a 1/1000 time base; encoder packets are rescaled before muxing** | The Matroska muxer writes packet pts verbatim into millisecond EBML fields (cluster timecodes and the segment Duration element) — with the encoder time base (1/48000 audio, 1/15360 x264) a 1 s WebM reported 48.312 s (last audio pts in sample units written as ms). MP4 accepts 1/1000 just as well, so one code path covers both containers. Frames are timestamped in the *encoder's* (possibly normalized) time base; packets are rescaled to the *stream's* (1/1000) time base. Verified with an isolated minimal writer: sample-unit pts → 48.312 s, ms pts → 1.008 s. |
| D-020 | **Export runs on a dedicated worker thread with deep-copied job data; fetchers are stateless** | Spec: no UI freezes. `ExportQueue` deep-copies each pending job (project snapshot + settings + fetch lambdas) into the worker at `start()`; the worker never touches shared state. The export fetchers open their own `VideoDecoder`/`AudioReader` per call (never the playback engine, never proxies — full quality). State flows back as queued signals; `Job::state` is only mutated on the UI thread. Cancel is a flag polled per frame. |
